# AILEO Console

## What it is
Operator console for the AILEO AI call-center. One place for the people who run the
service to watch traffic, read conversations, tune the agent, and manage outreach.

## Who uses it
Contact-center supervisors and the team that owns the agent. They are in a task, on a
desktop monitor, often while calls are live. Density and scanability matter more than
expression.

## Jobs (in priority order)
1. See what is happening now — call/chat volume, latency, sentiment, busy hours.
2. Read a conversation — full transcript, tool calls, latency, outcome, recording path.
3. Tune the agent — persona, knowledge base, tools, voice; upload KB documents and test search.
4. Work the queue — tickets that need a callback.
5. Run outreach — outbound campaigns and their per-target outcomes.
6. Wire the backend — outbound webhooks (CRM/ERP) and screen-pop target.

## Surface mode
Operate. The interface should disappear into the task: earned familiarity, one type
family, restrained color, consistent controls, real loading/empty/error states.

## Direction
Light, minimal, warm-neutral. Accent is a single deep green used only for primary
actions, current selection and state. Data is tabular. No decorative motion.
